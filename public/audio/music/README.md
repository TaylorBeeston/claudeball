# Park music tracks

Drop the tracks here named `<trigger>-<n>.ogg` (`homeRun-1.ogg`, `walkUp-3.ogg` ...), then run `npm run audio:music:index` to write
`manifest.json`. With no tracks the game plays its synthesised organ stingers. The list of tracks to make, with a prompt for each, is
in `docs/park-music-brief.md`. Check them in the game with `?musictest=homeRun` (or `all`).
