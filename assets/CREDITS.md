# Credits and licenses of third-party assets

Everything under `assets/` that was not authored in this repository comes from a source listed here. Only sources that can be used in a public MIT repository without login are used; every asset was checked at the time of use.

The MPFB add-on *source code* is GPL-3.0-or-later and is NOT part of this repository; the MakeHuman team states that output produced with MPFB (exports, meshes, renderings) is the user's own data (`LICENSE.md` of MPFB2, section D). |

Stored in this repository: `src/mpfb/base_body.npz` (the base mesh fitted to our rig, morph deltas, finger data), `src/mpfb/joints.json`, `src/mpfb/assets/*.npz` (fitted asset meshes), `src/mpfb/tex/*` (textures). They are regenerated by `src/mpfb_extract.py` (needs MPFB2 + the asset packs installed in Blender; not needed to run the normal build).
